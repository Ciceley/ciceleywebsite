# AGENTS.md — instructions for AI/LLM agents

This repo is the **Ciceley website**: a Hugo site (Stack theme) whose content is
authored in **Notion** and deployed via **CI → GHCR → ArgoCD**.

## The pipeline (don't reinvent it)

```
Notion DB ──scripts/notion-sync.mjs──▶ content/posts/*.md ──▶ PR
merge to main ──▶ .github/workflows/deploy.yml:
     hugo build ─▶ docker build ─▶ GHCR ─▶ bump tag in deploy/k8s/deployment.yaml
                                          └─ ArgoCD (bakuran-gitops) syncs it
```

## Layout

| Path | Purpose |
| --- | --- |
| `content/posts/<slug>/index.md` | posts (page bundles: `index.md` + images). **Generated by sync** |
| `content/about/`, `content/_index.md` | hand-written pages |
| `hugo.toml` | site config (title, menu, `baseURL`) |
| `assets/scss/custom.scss` | pink theme overrides |
| `layouts/` | template overrides (fonts, search JSON shim) |
| `themes/hugo-theme-stack` | theme (git submodule, pinned v4.0.3) |
| `scripts/notion-sync.mjs` | Notion → Markdown converter |
| `deploy/k8s/` | ArgoCD-applied manifests |
| `.github/workflows/` | `notion-sync` (scheduled PR), `build` (PR check), `deploy` (release) |

## Rules

1. **Don't hand-edit synced posts** (`content/posts/**` with a `notionId:`).
   Edit them in Notion; the sync overwrites them. Hand-written pages (no
   `notionId`) are safe.
2. **Don't hand-edit the image tag** in `deploy/k8s/deployment.yaml` — CI owns it.
3. `hugo.toml` `baseURL` is `https://ciceley.cc`; build locally with
   `nix develop -c hugo server` (dev server overrides baseURL).
4. Stack needs the **extended** Hugo build.
5. Never commit `.env` (git-ignored) or secrets.

## Validate before pushing

```bash
nix develop -c hugo --minify --gc     # build must be clean
```

CI runs the same on PRs (`.github/workflows/build.yml`).

## Adding a page

Create `content/<slug>/index.md` with front matter (`title`, `date`). It renders
via the theme automatically.

## Notion sync

`scripts/notion-sync.mjs` reads the `Writing` database (props: `Name`, `Slug`,
`Date`, `Description`, `Tags`, `Categories`, `Status`). Only `Status = Published`
is synced. Run `npm run sync` locally, or `npm run sync:pr` to open a PR.
